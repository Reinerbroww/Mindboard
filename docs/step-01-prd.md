# PRD — Mindboard

## 1. Masalah

Mahasiswa sering menggunakan mind map untuk membantu merangkum dan memahami materi kuliah. Namun, proses membuat mind map dari materi seperti PDF atau teks masih dilakukan secara manual.

Mahasiswa perlu membaca materi, menentukan konsep utama, menyusun hubungan antar konsep, kemudian membuat struktur mind map sendiri. Proses tersebut membutuhkan waktu dan usaha, terutama ketika materi yang digunakan cukup panjang.

Mindboard membantu mengotomatisasi proses tersebut menggunakan AI, sehingga mahasiswa dapat mengubah materi pembelajaran menjadi mind map secara otomatis tanpa harus menyusun struktur dari awal secara manual.

---

## 2. Target User

Target utama Mindboard adalah mahasiswa yang menggunakan mind map sebagai salah satu metode belajar dan ingin membuat rangkuman visual dari materi kuliah dengan lebih cepat.

Contoh penggunaan:

Seorang mahasiswa mendapatkan PDF materi Machine Learning. Daripada membaca materi kemudian menyusun mind map secara manual, mahasiswa dapat memasukkan PDF tersebut ke Mindboard. AI kemudian menganalisis materi dan membuat struktur mind map yang dapat dieksplorasi oleh mahasiswa.

---

## 3. Fitur Utama

### 1. Input Materi

Pengguna dapat memasukkan materi pembelajaran melalui:

- Teks
- File PDF

### 2. AI Mind Map Generation

AI menganalisis materi dan menghasilkan mind map yang berisi:

- Konsep utama
- Sub-konsep
- Hubungan antar konsep

Mind map memprioritaskan konsep utama terlebih dahulu agar pengguna dapat melihat gambaran besar materi. Detail konsep dapat dikembangkan secara bertahap melalui fitur Expand.

### 3. Interactive Whiteboard

Mind map ditampilkan dalam bentuk whiteboard interaktif.

Pengguna dapat:

- Zoom
- Pan
- Memilih konsep
- Memindahkan konsep

Mind map bukan berupa gambar statis, tetapi merupakan kumpulan objek yang dapat dieksplorasi.

### 4. Explain & Expand

Pengguna dapat memilih konsep tertentu untuk:

- **Explain** — mendapatkan penjelasan mengenai konsep berdasarkan materi yang digunakan.
- **Expand** — mengembangkan konsep menjadi sub-konsep baru yang ditambahkan langsung ke whiteboard.

### 5. Save Learning Map

Pengguna dapat menyimpan mind map yang telah dibuat dan membukanya kembali melalui dashboard.

---

## 4. Out of Scope

Fitur berikut tidak termasuk dalam MVP:

- Real-time collaboration
- Multiplayer whiteboard
- Mobile application
- Voice input
- Social features
- Gamification
- Public marketplace untuk berbagi mind map
- Advanced learning analytics

---

## 5. Value Proposition

Mindboard membantu mahasiswa mengubah materi kuliah menjadi mind map interaktif secara otomatis, sehingga mereka tidak perlu menyusun struktur mind map dari awal secara manual.

Mindboard bukan sekadar AI mind-map generator, tetapi menyediakan ruang belajar interaktif untuk membuat, mengeksplorasi, dan mengembangkan struktur materi.

---

## 6. Product Positioning

### ChatGPT / Gemini

AI general-purpose yang dapat digunakan untuk berbagai kebutuhan, termasuk membuat rangkuman dan mind map.

### Mindboard

Learning space yang secara khusus dirancang untuk mengubah materi pembelajaran menjadi knowledge map yang dapat dieksplorasi dan dikembangkan dalam whiteboard interaktif.

Workflow utama Mindboard:

Material
→ AI Analysis
→ Knowledge Map
→ Interactive Whiteboard
→ Explore
→ Explain / Expand
→ Save
