# STEP 2 — User Persona & User Flow

## 1. User Persona

### Nama
Raka Pratama

### Status
Mahasiswa

### Profil
Mahasiswa yang sering mendapatkan materi perkuliahan dalam bentuk PDF atau teks dan menggunakan mind map sebagai salah satu metode untuk merangkum materi.

### Kebutuhan
- Membuat mind map dari materi kuliah dengan lebih cepat.
- Mengurangi waktu yang dibutuhkan untuk menyusun mind map secara manual.
- Melihat konsep utama dan hubungan antar konsep dari suatu materi.
- Mengeksplorasi bagian tertentu dari materi secara lebih mendalam.

### Masalah Utama
Raka biasanya membuat mind map secara manual setelah mendapatkan materi kuliah. Ia perlu membaca materi, menentukan konsep yang penting, menyusun hubungan antar konsep, dan membuat struktur mind map sendiri. Proses tersebut membutuhkan waktu dan usaha, terutama ketika materi yang digunakan cukup panjang.

### Tujuan
Raka ingin mengubah materi kuliah menjadi mind map secara otomatis sehingga ia dapat langsung mengeksplorasi dan mempelajari struktur materi tanpa harus membuat mind map dari awal.

## 2. User Flow

### Flow Utama

Landing Page
→ Login / Register
→ Dashboard
→ Create New Map
→ Input Material
→ Upload PDF / Paste Text
→ Generate Mind Map
→ AI Processing
→ Interactive Whiteboard
→ Explore Mind Map
→ Select Concept
→ Explain / Expand
→ Save Map
→ Dashboard

---

## 3. Detail User Flow

### 1. Landing Page

User pertama kali membuka Mindboard.

**Tujuan:**
Memahami fungsi utama Mindboard dan memulai penggunaan aplikasi.

**Aksi utama:**
- Get Started
- Login

**Halaman berikutnya:**
Login / Register

---

### 2. Login / Register

User masuk ke akun atau membuat akun baru.

**Aksi:**
- Login
- Register

**Halaman berikutnya:**
Dashboard

---

### 3. Dashboard

User melihat daftar mind map yang pernah dibuat.

**Informasi utama:**
- Judul mind map
- Waktu terakhir diperbarui
- Mind map yang tersimpan

**Aksi utama:**
- Create New Map
- Open Map

**Halaman berikutnya:**
Create New Map atau Interactive Whiteboard

---

### 4. Create New Map

User memilih untuk membuat mind map baru.

**Aksi utama:**
- Upload PDF
- Paste Text

**Halaman berikutnya:**
Input Material

---

### 5. Input Material

User memasukkan materi pembelajaran.

**Input:**
- File PDF
- Teks materi

Setelah materi tersedia, user memilih:

**Generate Mind Map**

**Halaman berikutnya:**
AI Processing

---

### 6. AI Processing

Mindboard menganalisis materi dan membangun struktur mind map.

**Tahapan visual:**

Reading your material...
→ Finding key concepts...
→ Understanding relationships...
→ Building your knowledge map...
→ Drawing your mind map...

**Halaman berikutnya:**
Interactive Whiteboard

---

### 7. Interactive Whiteboard

Mind map hasil AI ditampilkan sebagai whiteboard interaktif.

User dapat:

- Zoom
- Pan
- Memilih konsep
- Memindahkan konsep

**Halaman berikutnya:**
Tetap di Interactive Whiteboard.

---

### 8. Explore Mind Map

User mengeksplorasi konsep yang tersedia pada mind map.

User dapat memilih salah satu konsep untuk melihat tindakan yang tersedia.

**Aksi:**
- Explain
- Expand

---

### 9. Explain / Expand

#### Explain

AI memberikan penjelasan mengenai konsep yang dipilih berdasarkan materi yang digunakan.

#### Expand

AI mengembangkan konsep yang dipilih menjadi sub-konsep baru dan menambahkannya ke whiteboard.

Setelah selesai, user kembali mengeksplorasi whiteboard.

**Halaman:**
Interactive Whiteboard

---

### 10. Save Map

Setelah selesai membuat atau mengeksplorasi mind map, user dapat menyimpannya.

**Aksi:**
Save

**Hasil:**
Mind map tersimpan pada akun user.

**Halaman berikutnya:**
Dashboard

---

## 5. User Goal

Tujuan akhir user adalah:

> Mengubah materi kuliah menjadi mind map interaktif secara otomatis, kemudian mengeksplorasi dan mengembangkan konsep yang terdapat di dalamnya tanpa harus membuat struktur mind map secara manual dari awal.
